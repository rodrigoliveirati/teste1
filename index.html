Principais comandos do GIT

Iniciando um repositório

  • git init - Inicializa um repositório Git vazio na pasta atual.
  • git clone <url> - Clona um repositório remoto para o computador local.

Verificando o estado

  • git status - Mostra o estado dos arquivos e alterações no repositório.
  • git log - Exibe o histórico de commits.

Adicionando e confirmando alterações

  • git add <arquivo> - Adiciona arquivos na área de preparação.
  • git add . - Adiciona todas as alterações da pasta atual.
  • git commit -m "mensagem" - Salva as alterações com uma mensagem descritiva.

Trabalhando com branches

  • git branch - Lista as branches existentes.
  • git checkout -b <nome> - Cria e troca para uma nova branch.
  • git checkout <nome> - Troca para uma branch existente.
  • git merge <nome> - Junta alterações de uma branch em outra.

Sincronizando com repositórios remotos

  • git remote -v - Mostra os repositórios remotos configurados.
  • git push origin <branch> - Envia commits para o repositório remoto.
  • git pull origin <branch> - Atualiza a branch local com as alterações do remoto.

Desfazendo alterações

  • git restore <arquivo> - Descarta alterações em um arquivo.
  • git reset --hard HEAD - Reverte todas as alterações locais para o último commit.

Visualizando diferenças

  • git diff - Mostra diferenças entre arquivos alterados e a última versão.
